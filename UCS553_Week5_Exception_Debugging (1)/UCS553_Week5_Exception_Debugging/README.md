# UCS553 Week 5 - Exception Handling & Debugging

Seven Java programs for the Week 5 experiment list.

## Programs
1. `q1/ExceptionHierarchyDemo.java` — common unchecked exceptions
2. `q2/NestedTryCatchDemo.java` — nested try-catch and finally
3. `q3/Calculator.java` — calculator with separate exception handlers
4. `q4/StudentResult.java` — custom InvalidMarksException, totals, percentage, grade
5. `q5/BankingApp.java` — deposits/withdrawals and custom banking exceptions
6. `q6/LoginSystem.java` — custom login exceptions and lock after 3 failed attempts
7. `q7/ShoppingCart.java` — shopping cart and requested exception hierarchy

## Compile and run
Each question is a standalone Java program. Open a terminal in its question folder and run:

```bash
javac FileName.java
java ClassName
```

For example:
```bash
cd q1
javac ExceptionHierarchyDemo.java
java ExceptionHierarchyDemo
```

The login program's sample credentials are username `student` and password `java123`.
